### `PROJECT 04 // LABEL NORMALIZER`

**Browser-first marketplace PDF processing pipeline**

A shipping-label normalization system for mixed Flipkart, Amazon and Meesho documents.

Instead of screenshotting labels, it works with PDF-native regions, produces exact 100 × 150 mm thermal-label pages, validates machine-readable codes and routes uncertain layouts into manual review.

**Engineering highlights**

- marketplace-specific adapter architecture
- PDF-native extraction / generation
- barcode + QR validation at thermal-printer resolution
- browser-local privacy-first processing
- FastAPI + Celery + Valkey server fallback
- Dockerized web/API/worker/PostgreSQL infrastructure

`Next.js` `TypeScript` `FastAPI` `PDF.js` `OpenCV` `Celery` `Valkey` `PostgreSQL` `Docker`
